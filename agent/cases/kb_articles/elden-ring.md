# 艾尔登法环（Elden Ring）

## 游戏名片

动作角色扮演 / 开放世界；FromSoftware 开发，Bandai Namco 发行；2022 年 2 月 25 日登陆 PlayStation、Xbox 与 PC；宫崎英高执导，乔治·R·R·马丁参与世界观构建；魂系列首次大规模开放世界化；单机为主，支持协作与入侵联机；买断制；主线与主要支线约 60–100 小时；Metacritic 与玩家口碑处于年度顶尖梯队。

## 游戏背景

玩家扮演「褪色者」，在「交界地」探索遗迹、洞窟与城堡，击败半神、收集大卢恩并决定世界命运。故事发生在「黄金树」时代末期：初始之王葛孚雷失去赐福，玛丽卡以法环碎片创造半神，诸神与半神发动「破碎战争」，交界地陷入混乱（盖利德腐败、利耶尼亚冰封、王城罗德尔灰雾封锁）。褪色者受指引树与梅琳娜召唤，目标修复法环或走向其他结局。世界观融合凯尔特神话、北欧史诗与马丁式家族政治；半神玛莲妮亚、拉塔恩、蒙格各代表不同悲剧。无明确善恶阵营，叙事借环境、物品与 NPC 支线碎片化呈现，鼓励多周目拼图。

## 配置需求

**最低配置（1080p / 30fps 低画质）**：Windows 10/11 64 位；Intel Core i5-8400 或 AMD Ryzen 3 3300X；8 GB 内存；NVIDIA GTX 1060 3GB / AMD RX 580 4GB；60 GB 可用空间（SSD 强烈建议）。**推荐配置（1080p / 60fps 高画质）**：Intel i7-8700K 或 Ryzen 5 3600X；16 GB 内存；RTX 2070 / RX 5700 XT。**高分辨率 / 光追**：RTX 3070 及以上更稳；开启光追时帧数波动明显，多数玩家选择关闭或仅开低档。主机版 PS5/Xbox Series X 提供性能模式与质量模式切换。Mod 与联机（入侵/协作）需保持游戏版本一致；Steam Deck 可玩但需降画质。首次进入建议在设置中关闭「自动旋转镜头」并根据习惯调整锁定距离。

## 玩法

核心循环为 **探索 → 挑战 Boss → 获得卢恩与装备 → 升级与加点 → 推进主线/支线**。战斗强调 stamina 管理、翻滚无敌帧与读招：轻攻击、重攻击、战技与魔法/祷告可自由组合。开放世界中可见即所得，重要地点通过地图标记与赐福（篝火）网络串联。骑马托雷特可二段跳与冲刺，适合跑图与部分 Boss 战（如碎星拉塔恩前期可骑马削血）。职业（遗器）决定初始属性与装备倾向，但后期可通过洗点与武器质变自由转型。联机支持召唤协助（消耗唤勾指药）与入侵 PVP；部分区域为 PVP 强制或 Boss 房间禁止入侵。多结局取决于是否完成特定 NPC 任务链（如菈妮、食粪者、完美律法等），一周目约 60–100 小时可完成主线与主要支线。

## 注意事项

新手切忌贪刀：先观察 Boss 前摇再输出，死亡会掉落卢恩，需回死亡点拾取。建议优先提升 **生命力** 至 40 左右再堆伤害。早期在宁姆格福南部拿到灵马哨笛，大幅缩短跑图时间。未看攻略也可游玩，但若卡关可查阅赐福旁留言或召唤协助。部分区域（盖利德腐败、圣树）敌人等级远高于周边，勿过早深入。备份存档：PC 用户复制存档文件夹以防误选结局或 NPC 死亡。联机时注意关闭 EAC 冲突的修改器。DLC《黄金树幽影》需本体通关并击败特定 Boss 后进入，难度显著高于本体，建议等级 150+ 再挑战。
