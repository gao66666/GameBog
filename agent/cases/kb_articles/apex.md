# APEX 英雄（Apex Legends）

## 游戏名片

战术大逃杀 / 英雄射击；Respawn Entertainment 开发，Electronic Arts 发行；2019 年 2 月免费上线；PC（Steam/Origin）、PlayStation、Xbox、Switch 及部分移动端；60 人（20 队）三人小队；与《泰坦陨落》共享宇宙但无泰坦驾驶；赛季制运营与 ALGS 电竞；免费游玩，内购为外观与 Battle Pass，无 pay-to-win 数值。

## 游戏背景

外域为边境星域，IMC 与民兵战争结束后各殖民星球自治。「Apex 竞赛」由辛迪加等财团赞助，传奇为名声、复仇或赎罪参战。角色如寻血猎犬、直布罗陀、恶灵、华森等有漫画与赛季剧情补充。地图含 Kings Canyon、World's Edge、Olympus、Storm Point 等，各有轨道炮、热气球、野生动物等机制；时间线随赛季 CG 推进，新传奇入场常伴随地图事件。

## 配置需求

**最低配置**：Windows 7 64 位；AMD FX-4350 / Intel i3-6300；6 GB RAM；Radeon HD 7730 / GT 640；56 GB 空间。**推荐**：Ryzen 5 / i5-6400；8 GB RAM；GTX 970 / RX 470。**竞技 144fps**：RTX 3060 及以上 + 144Hz 显示器；CPU 单核性能影响大。Origin/EA App 与 Steam 版互通需绑定 EA 账号。主机 60fps 为主，PS5/XSX 支持 120fps 模式（视模式）。网络延迟（ping）比显卡更关键，建议有线连接并选最近数据中心。反作弊 Easy Anti-Cheat 禁止常见外挂与部分 overlay 注入。

## 玩法

匹配流程：选传奇 → 跳伞队长选落点 → 搜刮（武器分级白蓝紫金、护甲进化、背包扩容）→ 听圈声与扫描信息 → 遭遇战（TTK 中等，护甲机制允许拉枪线）→ 决赛圈站位与技能配合。武器类型涵盖突击步枪、冲锋枪、狙击、霰弹、能量武器等，需适配附件（镜、握把、扩容）。复活机制：拾取队友旗帜到重生信标或新生成器。排位赛累积 RP，分段从青铜到 apex 猎杀者（顶级有名额限制）。 firing range 可练枪；Team Deathmatch 等限时模式用于 warm-up。语音 ping 系统可标记物品与敌人，无需麦克风也能沟通。

## 注意事项

**勿孤狼深入**：三人队分散极易被逐个击破，保持可视距离与交叉火力。落点避免热门「高资源区」除非练枪或排位高分段。听声辨位重要，戴耳机并关闭多余音乐。排位勿频繁换传奇，专精 2–3 名更易上分。举报作弊与宏，EA 封禁周期较长。服务器问题可能导致 hit 注册争议，低 ping 仍可能遇「no reg」。Battle Pass 有时间限制，非必须购买。更新后读 patch notes，武器平衡常改（如 R-99、和平使者历史多次调整）。移动端与 PC 不互通匹配。健康游戏：避免长时间排位导致疲劳操作下滑。
