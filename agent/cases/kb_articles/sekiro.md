# 只狼：影逝二度（Sekiro: Shadows Die Twice）

## 简介

《只狼：影逝二度》是 FromSoftware 与 Activision 联合发行的动作冒险游戏，2019 年 3 月发售。与《黑暗之魂》《血源诅咒》不同，本作聚焦日本战国末期的忍者题材，主角「狼」为侍奉皇子「九郎」的独臂忍人，拥有可伸缩的忍义手与复活能力。游戏强调 **弹刀（Parry）**、架势条与忍杀处决，而非翻滚与 stamina 为主的魂系节奏。地图采用半互通设计，通过忍义具与技能解锁垂直动线。叙事相对线性但人物关系紧凑，苇名国、源之宫与内府军的冲突贯穿主线。难度曲线陡峭，被玩家称为「音游级」格挡训练，通关成就感极强。

## 游戏背景

故事发生于虚构的苇名国，该地因稀缺资源「樱龙之力」与内府军长期对峙。苇名一心曾以「盗国」手段夺取权力，如今国势衰微，皇子九郎被苇名弦一郎软禁于天守阁。狼受永真与佛雕师指引，需夺回九郎并寻找「常樱不死斩」以切断不死诅咒。支线涉及鬼刑部、蛇眼、破戒僧、樱龙等超自然存在，以及源之宫贵族与「返魂香」秘密。时间线存在少量时空穿越（源之宫为过去），整体叙事通过回忆、物品与 NPC 对话补完。无角色创建，固定扮演狼，通过技能与忍义具分支体现 build 差异。

## 配置需求

**最低配置**：OS 64 位 Windows 7 SP1；Intel Core i3-2100 / AMD FX-6300；4 GB RAM；NVIDIA GTX 760 / AMD Radeon HD 7950；25 GB HDD 空间。**推荐配置**：Windows 10；Intel Core i5-2500K / AMD Ryzen 3 1200；8 GB RAM；GTX 970 / RX 570；SSD。**高帧率格斗体验**：144Hz 显示器 + GTX 1060 6GB 以上更利于练习弹刀节奏。主机版 PS4/Xbox One 稳定 30fps，PS4 Pro 部分场景更高。无官方联机；PC 版 Mod 以外观与练习工具为主，联机 Mod 非官方。键鼠与手柄均可，多数高手推荐手柄；PC 可绑定侧键辅助忍义具。

## 玩法

战斗核心是 **架势（Posture）**：连续完美弹刀会削满敌人架势条，触发忍杀。自身架势满则大硬直。死亡可消耗「回生」原地复活一次（有次数限制，需消耗「回生之力」）。忍义手可装备斧（破盾）、爆竹（对妖）、长枪（拉人）、铁扇（弹返投射物）等，消耗「忍义具」次数。技能树分忍杀、苇名、忍具、义手四系，需技能点与材料解锁。探索依靠钩绳、下潜、贴墙与忍杀暗杀；无明显 RPG 等级，攻击力由「记忆」道具（天守阁四本）提升。Boss 战多为一对一，需背板与节奏；部分可逃课（如蝴蝶夫人踩头、破戒僧卡柱），但建议至少掌握基础弹刀。多周目 NG+ 敌人血量与伤害提升，可收集剩余技能与结局分支（修罗 / 断臂 / 普通）。

## 注意事项

**不要按魂系习惯一味翻滚**：多数攻击应弹刀或完美格挡，翻滚无敌帧短且无法有效削架势。赤鬼、火牛等「野兽类」敌人不吃弹刀逻辑，多用爆竹、火焰与绕后。佛雕师与皇子相关支线影响结局，错过时间点需 NG+。「剑圣一心」为公认最难 Boss，建议储备攻糖、消怖糖与乌鬼烟。源之宫需事先收集「樱龙泪」相关道具以免锁结局。学习弹刀可找苇名流天守阁下的「木桩」反复练。PC 版注意防修改器导致存档损坏。若卡关过久，可暂时推进主线提升攻击力再回头挑战。
