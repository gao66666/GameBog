# 巫师 3：狂猎（The Witcher 3: Wild Hunt）

## 游戏名片

动作角色扮演 / 开放世界；CD Projekt Red 开发；2015 年 5 月全球发布，基于萨普科夫斯基小说改编；PC、PS4、Xbox One、Switch 及次世代；2022 年底免费次世代更新（光追、性能模式、中文配音）；单机；买断 + DLC；主线与主要支线约 120–200 小时；TGA 2015 年度游戏。

## 游戏背景

时间线继《巫师 2》，北方王国陷入第三次尼弗迦德战争。玩家扮演猎魔人杰洛特，在威伦、诺维格瑞、史凯利杰、陶森特等地寻找养女希里，阻止狂猎之王入侵。恩希尔率军北上，拉多维德统治瑞达尼亚，松鼠党与烈焰蔷薇交织。狂猎为异世界精灵骑兵，追踪拥有上古之血的希里；希里可穿越时空，艾瑞汀欲用其血征服诸界。威伦男爵悲剧、精灵矮人矛盾、宗教审判等支线影响 NPC 命运与结局（叶奈法/特莉丝/希里等）。世界观可独立于原著阅读。

## 配置需求

**最低配置（1080p 30fps 低画质）**：Intel Core i5-2500K / AMD Phenom II X4 940；6 GB RAM；NVIDIA GTX 660 / AMD R9 390；40 GB SSD。**推荐配置（1080p 60fps 高画质）**：Intel i7-3770 / AMD FX-8350；8 GB RAM；GTX 1060 6GB / RX 580。**次世代光追（4K 60fps）**：RTX 3080 / RX 6800 XT 及以上；16 GB RAM；SSD 必需。次世代更新后支持 DLSS 与 FSR 超分辨率，显著改善帧率。Switch 版画质大幅压缩但掌机可玩，存档不与 PC 互通。Mod 社群庞大（次世代版本部分 Mod 需适配），常见增强包括高清材质、快速旅行、战斗重平衡等。Steam Deck 推荐中低画质 40fps 锁帧。

## 玩法

第三人称动作 RPG：**轻/重攻击 + 法印（昆恩护盾、伊格尼火焰、亚克西魅惑、阿尔德冲撞、亚登陷阱）+ 炼金术（魔药、煎药、剑油）**。前期需频繁翻滚与法印周旋，后期炼金猫熊流、瘾头狼派等 build 成型后战力剧增。任务系统有核心（主线）、支线、猎魔委托与寻宝四种，大量支线影响主线结局选项。开放世界问号（宝藏与怪物巢穴）丰富但部分可跳过。**昆特牌**内置可收集卡牌游戏，深度可观，有独立比赛与 GOG 联动的独立版。抉择多为灰度：杀死怪兽可拿报酬但可能危害村民，放过有时获得信息或后援。多周目继承装备与技能但重置任务状态，新增「新游戏+」模式。

## 注意事项

**前期点技能容错低**：优先解锁法印强化与炼金耐力，后期再补剑术。昆恩护盾是新手保命核心，养成进战前开盾习惯。**药剂与煎药毒性管理**：毒性超上限扣血，配合「耐性」技能可连续服用多瓶。剑油每战涂一次（自动生效），常备「吸血鬼」「食尸生物」「诅咒生物」剑油应对大部分遭遇。**白果园为主要教学区域**，全清后再推进主战节省时间。DLC 顺序推荐主线→石之心（中期可进入）→血与酒（主线通关后），血与酒新增突变系统大幅提升强度上限。次世代版勿忘关闭模糊与景深以获得更清晰画面。存档错乱可手动备份「我的文档\The Witcher 3」目录下的存档文件夹。
